    Worksheet Review Activity: Exponentials and Logarithms
    

    This review covers exponential models, logarithms, and solving exponential and logarithmic equations, including equations that come from applications and from heating and cooling problems. Each section starts with a short summary and worked examples, then moves from basic problems to harder ones. A mixed set of additional practice is at the end.
    🔗
    • Throughout this activity, \(\ln(x)\) means the logarithm base \(e\) and \(\log(x)\) means the logarithm base \(10\text{.}\)
      🔗
    • The only logarithm rule you need is the exponent rule, \(\ln(M^p) = p\ln(M)\text{,}\) which holds whenever \(M \gt 0\text{.}\) It works the same way for \(\log\) and for any other base.
      🔗
    • Avoid rounding in the middle of a problem. Keep exact values like \(\ln(5/3)\text{,}\) or store them in your calculator, and round only your final answer.
      🔗
    • Several sections include a short video if you would like a refresher.
      🔗
    🔗

    Exponential Models.

    Exponential Functions.

    An exponential function has the form \(f(x) = a\cdot b^x\text{,}\) where \(a\) is the initial value (the output when \(x = 0\)) and \(b\) is the growth or decay factor. Each time \(x\) increases by \(1\text{,}\) the output is multiplied by \(b\text{.}\)
    🔗
    • If \(b \gt 1\text{,}\) the function is growing. If \(0 \lt b \lt 1\text{,}\) the function is decaying.
      🔗
    • If a quantity increases by a percent rate \(r\) (written as a decimal) each time period, then \(b = 1 + r\text{.}\) If it decreases by a percent rate \(r\text{,}\) then \(b = 1 - r\text{.}\)
      🔗
    • A linear function adds the same amount each step. An exponential function multiplies by the same factor each step.
      🔗
    • Some models use the number \(e \approx 2.71828\) as the base and are written \(f(x) = a e^{kx}\text{.}\) These grow when \(k \gt 0\) and decay when \(k \lt 0\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Example 11. Worked Example.

    A town has 4,200 residents, and its population grows by \(3\%\) each year. Write an exponential model \(P(x)\) for the population \(x\) years from now. Then use it to predict the population in \(10\) years.
    🔗
    Solution.
    The initial value is \(a = 4200\text{.}\) The population grows by \(3\%\text{,}\) so \(r = 0.03\) and the growth factor is \(b = 1 + 0.03 = 1.03\text{.}\) The model is \(P(x) = 4200(1.03)^x\text{.}\)
    🔗
    To predict the population in \(10\) years, substitute \(x = 10\text{.}\)
    \begin{align*} P(10) \amp= 4200(1.03)^{10}\\ \amp\approx 5644.45 \end{align*}
    🔗
    The town will have about 5,644 residents in \(10\) years.
    🔗
    A common error is to use \(b = 0.03\) or \(b = 3\text{.}\) The factor \(1.03\) says that each year the town keeps all of its current population (the \(1\)) and adds \(3\%\) more (the \(0.03\)).
    🔗
    🔗
    🔗

    Example 12. Worked Example.

    Could the table below represent a linear function, an exponential function, or neither? If it is linear or exponential, write a formula for \(f(x)\text{.}\)
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\)
    \(f(x)\) \(2000\) \(1600\) \(1280\) \(1024\)
    Solution.
    The \(x\)-values go up by \(1\) each time, so we can compare consecutive outputs directly.
    🔗
    Check for linear (differences):
    \begin{align*} 1600 - 2000 \amp= -400\\ 1280 - 1600 \amp= -320\\ 1024 - 1280 \amp= -256 \end{align*}
    🔗
    The differences are not constant, so \(f\) is not linear.
    🔗
    Check for exponential (ratios):
    \begin{align*} \frac{1600}{2000} \amp= 0.8\\ \frac{1280}{1600} \amp= 0.8\\ \frac{1024}{1280} \amp= 0.8 \end{align*}
    🔗
    Every ratio is \(0.8\text{,}\) so \(f\) could be exponential with decay factor \(b = 0.8\text{.}\) The output at \(x = 0\) is \(2000\text{,}\) so \(a = 2000\) and \(f(x) = 2000(0.8)^x\text{.}\) A factor of \(0.8 = 1 - 0.2\) means the output loses \(20\%\) each step.
    🔗
    Just like with linear tables, be careful when the \(x\)-values are not evenly spaced. Comparing ratios of consecutive outputs only works this simply when the inputs go up by the same amount each time.

    Logarithms as Inverses of Exponentials.

    Logarithms.

    A logarithm is an exponent. The expression \(\log_b(y)\) asks: what power do we raise \(b\) to in order to get \(y\text{?}\)
    🔗
    \begin{gather*} \log_b(y) = x \quad \text{means the same thing as} \quad b^x = y \end{gather*}
    🔗
    In both forms, the base stays the base. In log form, the logarithm is equal to the exponent.
    🔗
    • Two bases have their own notation: \(\log(x)\) means \(\log_{10}(x)\text{,}\) and \(\ln(x)\) (the natural log) means \(\log_e(x)\text{.}\)
      🔗
    • The function \(\log_b(x)\) is the inverse of \(b^x\text{,}\) so each one undoes the other: \(\log_b(b^x) = x\) and \(b^{\log_b(x)} = x\text{.}\) In particular, \(\ln(e^x) = x\) and \(e^{\ln(x)} = x\text{.}\)
      🔗
    • The base of a logarithm must be positive and cannot be \(1\text{.}\) Because \(b^x\) is always positive, the input of a logarithm must also be positive. The output of a logarithm can be positive, negative, or zero.
      🔗
    • Two values worth knowing: \(\log_b(1) = 0\) because \(b^0 = 1\text{,}\) and \(\log_b(b) = 1\) because \(b^1 = b\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Example 13. Worked Example.

    The table on the left shows some values of \(f(x) = 2^x\text{.}\) Use it to fill in a table for the inverse function, \(f^{-1}(x) = \log_2(x)\text{.}\)
    🔗
    \(x\) \(-1\) \(0\) \(1\) \(2\) \(3\)
    \(2^x\) \(\frac{1}{2}\) \(1\) \(2\) \(4\) \(8\)
    \(x\) \(\frac{1}{2}\) \(1\) \(2\) \(4\) \(8\)
    \(\log_2(x)\)
    Solution.
    An inverse function swaps inputs and outputs. Since \(2^3 = 8\text{,}\) the inverse sends \(8\) back to \(3\text{,}\) so \(\log_2(8) = 3\text{.}\) Doing the same for each column gives \(\log_2\left(\frac{1}{2}\right) = -1\text{,}\) \(\log_2(1) = 0\text{,}\) \(\log_2(2) = 1\text{,}\) \(\log_2(4) = 2\text{,}\) and \(\log_2(8) = 3\text{.}\)
    🔗
    Notice that every output of \(2^x\) is positive, so every input of \(\log_2(x)\) is positive. The outputs of \(\log_2(x)\text{,}\) on the other hand, include \(-1\) and \(0\text{.}\)
    🔗

    Example 14. Worked Example.

    Rewrite each equation in the other form.
    🔗
    1. \(\displaystyle 2^5 = 32\)
      🔗
    2. \(\displaystyle 4^{-1} = \frac{1}{4}\)
      🔗
    3. \(\displaystyle \log_3(81) = 4\)
      🔗
    4. \(\displaystyle \ln(x) = 5\)
      🔗
    🔗
    Solution.
    1. The base is \(2\) and the exponent is \(5\text{.}\) The log equals the exponent, so \(\log_2(32) = 5\text{.}\)
      🔗
    2. The base is \(4\) and the exponent is \(-1\text{,}\) so \(\log_4\left(\frac{1}{4}\right) = -1\text{.}\)
      🔗
    3. The base is \(3\) and the log value \(4\) is the exponent, so \(3^4 = 81\text{.}\) It can help to read \(\log_3(81) = 4\) out loud as “3 to the 4th is 81.”
      🔗
    4. Since \(\ln\) is the log base \(e\text{,}\) this says \(\log_e(x) = 5\text{,}\) so \(e^5 = x\text{.}\)
      🔗

    Example 15. Worked Example.

    Evaluate each expression without a calculator.
    🔗
    1. \(\displaystyle \log_2(16)\)
      🔗
    2. \(\displaystyle \log(1000)\)
      🔗
    3. \(\displaystyle \log_5\left(\frac{1}{25}\right)\)
      🔗
    4. \(\displaystyle \log_9(3)\)
      🔗
    5. \(\displaystyle \log_7(1)\)
      🔗
    6. \(\displaystyle \ln(e^4)\)
      🔗
    7. \(\displaystyle 10^{\log(6)}\)
      🔗
    🔗
    Solution 1. Method 1: Ask “what power?”
    1. \(2\) to what power is \(16\text{?}\) Since \(2^4 = 16\text{,}\) \(\log_2(16) = 4\text{.}\)
      🔗
    2. This is base \(10\text{.}\) Since \(10^3 = 1000\text{,}\) \(\log(1000) = 3\text{.}\)
      🔗
    3. Since \(5^2 = 25\text{,}\) we have \(5^{-2} = \frac{1}{25}\text{,}\) so \(\log_5\left(\frac{1}{25}\right) = -2\text{.}\)
      🔗
    4. Since \(\sqrt{9} = 3\text{,}\) we have \(9^{1/2} = 3\text{,}\) so \(\log_9(3) = \frac{1}{2}\text{.}\)
      🔗
    5. Any base to the \(0\) power is \(1\text{,}\) so \(\log_7(1) = 0\text{.}\)
      🔗
    6. By the inverse property, \(\ln(e^4) = 4\text{.}\)
      🔗
    7. By the inverse property, \(10^{\log(6)} = 6\text{.}\)
      🔗
    🔗
    🔗
    Solution 2. Method 2: Set it equal to \(x\) and match bases
    When the answer is not obvious, set the log equal to \(x\text{,}\) rewrite in exponential form, and write both sides with the same base. For part (d):
    \begin{align*} \log_9(3) \amp= x\\ 9^x \amp= 3\\ (3^2)^x \amp= 3^1\\ 3^{2x} \amp= 3^1\\ 2x \amp= 1\\ x \amp= \frac{1}{2} \end{align*}
    🔗
    The same idea works for part (c): \(5^x = \frac{1}{25} = 5^{-2}\text{,}\) so \(x = -2\text{.}\) This is exactly the matching bases method we will use to solve exponential equations in the next section.
    🔗

    Solving Exponential Equations.

    Solving Exponential Equations.

    Step 1: Isolate the exponential part. Use the same steps you would use on a linear equation: undo addition or subtraction first, then undo multiplication or division. Do not combine a coefficient with the base. For example, \(3\cdot 2^x\) is not \(6^x\text{,}\) because the exponent only applies to the \(2\text{.}\)
    🔗
    Step 2: Choose a method.
    • Matching bases. If both sides can be written as powers of the same base, set the exponents equal: if \(b^M = b^N\text{,}\) then \(M = N\text{.}\)
      🔗
    • Taking a log of both sides. Take \(\ln\) (or \(\log\)) of both sides and use the exponent rule \(\ln(M^p) = p\ln(M)\) to bring the exponent down. This works even when the bases cannot be matched, as long as the isolated exponential equals a positive number. If it equals zero or a negative number, the equation has no solution.
      🔗
    • Rewriting in log form. If \(b^x = y\text{,}\) then \(x = \log_b(y)\text{.}\) This is especially quick for base \(e\text{:}\) if \(e^x = y\text{,}\) then \(x = \ln(y)\text{.}\)
      🔗
    🔗
    Give the exact answer, such as \(\frac{\ln(11)}{\ln(2)}\text{,}\) and then round at the very end if a decimal is needed.
    🔗
    🔗
    🔗

    Example 17. Worked Example.

    Solve each equation.
    🔗
    1. \(\displaystyle 3^{x+1} = 81\)
      🔗
    2. \(\displaystyle 4^x = 8\)
      🔗
    🔗
    Solution 1. Method 1: Matching bases
    (a) Since \(81 = 3^4\text{,}\) we can write both sides as powers of \(3\text{.}\)
    \begin{align*} 3^{x+1} \amp= 3^4\\ x + 1 \amp= 4\\ x \amp= 3 \end{align*}
    🔗
    (b) Neither \(8\) nor \(4\) is a power of the other, but both are powers of \(2\text{:}\) \(4 = 2^2\) and \(8 = 2^3\text{.}\)
    \begin{align*} (2^2)^x \amp= 2^3\\ 2^{2x} \amp= 2^3\\ 2x \amp= 3\\ x \amp= \frac{3}{2} \end{align*}
    🔗
    🔗
    Solution 2. Method 2: Taking \(\ln\) of both sides
    (a) Take \(\ln\) of both sides and bring the exponent down. Keep parentheses around \(x + 1\text{,}\) since the whole exponent comes down.
    \begin{align*} \ln\left(3^{x+1}\right) \amp= \ln(81)\\ (x+1)\ln(3) \amp= \ln(81)\\ x + 1 \amp= \frac{\ln(81)}{\ln(3)} = 4\\ x \amp= 3 \end{align*}
    🔗
    (b)
    \begin{align*} \ln(4^x) \amp= \ln(8)\\ x\ln(4) \amp= \ln(8)\\ x \amp= \frac{\ln(8)}{\ln(4)} = 1.5 \end{align*}
    🔗
    Both methods give the same answers. Matching bases is quicker when it works, but taking a log of both sides works even when the bases cannot be matched.
    🔗
    🔗
    🔗

    Example 18. Worked Example.

    Solve \(2\cdot 5^x - 3 = 17\text{.}\) Give an exact answer and a decimal rounded to two places.
    🔗
    Solution 1. Method 1: Isolate, then take \(\ln\)
    First isolate the exponential part, undoing the subtraction and then the multiplication.
    \begin{align*} 2\cdot 5^x - 3 \amp= 17\\ 2\cdot 5^x \amp= 20\\ 5^x \amp= 10 \end{align*}
    🔗
    Since \(10\) is not a power of \(5\text{,}\) matching bases will not work. Take \(\ln\) of both sides.
    \begin{align*} \ln(5^x) \amp= \ln(10)\\ x\ln(5) \amp= \ln(10)\\ x \amp= \frac{\ln(10)}{\ln(5)} \approx 1.43 \end{align*}
    🔗
    This is reasonable: \(5^1 = 5\) and \(5^2 = 25\text{,}\) so the exponent that gives \(10\) should be between \(1\) and \(2\text{.}\)
    🔗
    🔗
    Solution 2. Method 2: Isolate, then take \(\log\)
    Any logarithm works as long as we use the same one on both sides. Starting from \(5^x = 10\text{:}\)
    \begin{align*} \log(5^x) \amp= \log(10)\\ x\log(5) \amp= 1\\ x \amp= \frac{1}{\log(5)} \approx 1.43 \end{align*}
    🔗
    The exact answer looks different, but \(\frac{1}{\log(5)}\) and \(\frac{\ln(10)}{\ln(5)}\) are the same number.
    🔗
    🔗
    Solution 3. Method 3: Isolate, then rewrite in log form
    Starting from \(5^x = 10\text{,}\) log form gives the exact answer \(x = \log_5(10)\) right away. To get a decimal, either use a calculator that allows a base \(5\) log, or go back to Method 1.
    🔗
    A common error is to combine the \(2\) and the \(5\) into \(10^x\text{.}\) The exponent is only on the \(5\text{,}\) so the \(2\) has to be divided off first.

    Solving Logarithmic Equations.

    Solving Logarithmic Equations.

    Step 1: Isolate the logarithm. Undo addition or subtraction first, then multiplication or division.
    🔗
    Step 2: Rewrite in exponential form. If \(\log_b(M) = c\text{,}\) then \(M = b^c\text{.}\) For the natural log, \(\ln(M) = c\) means \(M = e^c\text{.}\) For the common log, \(\log(M) = c\) means \(M = 10^c\text{.}\) Some people call this step “exponentiating both sides,” since \(e^{\ln(M)} = e^c\) simplifies to \(M = e^c\) by the inverse property. Either way, you get the same equation.
    🔗
    Step 3: Solve what is left. This is usually a linear equation.
    🔗
    Step 4: Check. The input of each logarithm must be positive. The solution itself is allowed to be negative; only the input to the log matters.
    🔗
    If there is a power inside the log, you may use the exponent rule \(\ln(M^p) = p\ln(M)\text{.}\) Be careful: a logarithm does not distribute over addition or subtraction, so \(\ln(3x - 1)\) is not \(\ln(3x) - \ln(1)\text{.}\)
    🔗
    🔗
    🔗

    🔗

    Applications of Exponential Models.

    Solving Exponential Applications.

    Read the question carefully to see what is unknown.
    🔗
    • If you are given a time and asked for the amount, substitute the time for \(x\) and evaluate.
      🔗
    • If you are given an amount and asked “when,” set the function equal to that amount and solve for \(x\text{:}\) isolate the exponential part (usually by dividing by the initial value), take \(\ln\) of both sides, and solve.
      🔗
    • For doubling time, set the function equal to twice the initial value. For half-life, set it equal to half the initial value. The initial value always divides out, so doubling time and half-life do not depend on the starting amount.
      🔗
    • Avoid rounding until the end. Keep ratios such as \(\frac{5}{3}\) as fractions, and keep log values stored in your calculator. Small rounding errors in the middle of a problem can grow into noticeable errors in the final answer.
      🔗
    • Finish with a sentence that answers the question, including units.
      🔗

    Example 25. Worked Example.

    Asami deposits $3,000 into an account that earns \(5\%\) interest each year, so the balance \(x\) years after the deposit is \(A(x) = 3000(1.05)^x\text{.}\) How long will it take for the balance to reach $5,000?
    🔗
    Solution.
    Set \(A(x) = 5000\) and solve.
    \begin{align*} 3000(1.05)^x \amp= 5000\\ (1.05)^x \amp= \frac{5}{3}\\ x\ln(1.05) \amp= \ln\left(\frac{5}{3}\right)\\ x \amp= \frac{\ln(5/3)}{\ln(1.05)} \approx 10.47 \end{align*}
    🔗
    The balance reaches $5,000 after about \(10.47\) years. (If the bank adds interest only once a year, the balance first passes $5,000 when the interest is added at the end of year \(11\text{.}\))
    🔗
    In log form, the exact answer can also be written \(x = \log_{1.05}\left(\frac{5}{3}\right)\text{.}\) It is the same number.
    🔗
    To see why early rounding matters, suppose we rounded \(\ln(1.05) \approx 0.0488\) to \(0.05\text{.}\) Then we would get \(\frac{\ln(5/3)}{0.05} \approx 10.22\) years, which is off by about three months.

    Heating and Cooling.

    Newton’s Law of Cooling.

    When an object is placed in surroundings that stay at a constant temperature, the temperature of the object \(x\) minutes after it is placed there is
    \begin{gather*} F(x) = ae^{-kx} + c \end{gather*}
    for some constants \(a\text{,}\) \(c\text{,}\) and \(k\text{,}\) where \(k \gt 0\text{.}\)
    🔗
    • \(c\) is the temperature of the surroundings. As \(x\) gets larger, \(e^{-kx}\) gets closer to \(0\text{,}\) so \(F(x)\) gets closer and closer to \(c\text{.}\) The object never passes the surrounding temperature.
      🔗
    • \(a + c\) is the initial temperature of the object, since \(F(0) = ae^0 + c = a + c\text{.}\) That means \(a\) is the initial temperature minus \(c\text{,}\) or how far the object starts from the surrounding temperature.
      🔗
    • The same formula works for cooling and for warming. A cooling object starts above \(c\text{,}\) so \(a\) is positive. A warming object starts below \(c\text{,}\) so \(a\) is negative.
      🔗
    • Be careful: in this model \(a\) is not the initial temperature, even though \(a\) was the initial value in \(f(x) = a\cdot b^x\text{.}\) Adding \(c\) shifts the graph up, so the initial temperature is \(a + c\text{.}\)
      🔗
    • Once you know \(a\) and \(c\text{,}\) one more temperature reading is enough to find \(k\text{.}\) To solve for \(x\) or for \(k\text{,}\) isolate the exponential part in this order: subtract \(c\text{,}\) then divide by \(a\text{,}\) then take \(\ln\) of both sides. Do not combine \(a\) and \(c\text{;}\) they are not like terms.
      🔗
    🔗
    🔗
    🔗

    Example 27. Worked Example.

    A cup of coffee at \(190^\circ\)F is set on a table in a room that is \(70^\circ\)F. For this cup, \(k = 0.05\) per minute.
    🔗
    1. Write a model \(F(x)\) for the temperature of the coffee \(x\) minutes after it is set on the table.
      🔗
    2. What is the temperature of the coffee after \(10\) minutes?
      🔗
    3. When will the coffee be \(120^\circ\)F?
      🔗
    🔗
    Solution.
    (a) The room is \(70^\circ\)F, so \(c = 70\text{.}\) The coffee starts at \(190^\circ\)F, so \(a + c = 190\) and \(a = 190 - 70 = 120\text{.}\) The model is \(F(x) = 120e^{-0.05x} + 70\text{.}\)
    🔗
    A common error is to use \(a = 190\text{.}\) The initial temperature is \(a + c\text{,}\) so \(a\) is the difference between the coffee and the room.
    🔗
    (b) \(F(10) = 120e^{-0.5} + 70 \approx 142.78\text{.}\) After \(10\) minutes the coffee is about \(142.78^\circ\)F.
    🔗
    (c) Set \(F(x) = 120\text{.}\) Subtract \(70\) first, then divide by \(120\text{.}\)
    \begin{align*} 120e^{-0.05x} + 70 \amp= 120\\ 120e^{-0.05x} \amp= 50\\ e^{-0.05x} \amp= \frac{5}{12}\\ -0.05x \amp= \ln\left(\frac{5}{12}\right)\\ x \amp= \frac{\ln(5/12)}{-0.05} \approx 17.51 \end{align*}
    🔗
    The coffee reaches \(120^\circ\)F after about \(17.51\) minutes.
    🔗
    Another way to think about this: the term \(120e^{-0.05x}\) is how many degrees the coffee is above room temperature. Asking when the coffee is \(120^\circ\)F is the same as asking when it is \(50\) degrees above the room, which is exactly the second line above.
    🔗
    Another common error is to combine \(120\) and \(70\) and write \(190e^{-0.05x}\text{.}\) The \(120\) is multiplied by \(e^{-0.05x}\) and the \(70\) is added afterward, so they are not like terms, and the \(70\) has to be subtracted first.

    Example 28. Worked Example.

    A pie is taken out of a \(350^\circ\)F oven and set on the counter in a \(72^\circ\)F kitchen. Let \(F(x)\) be the temperature of the pie \(x\) minutes after it comes out of the oven. After \(15\) minutes, the pie is \(220^\circ\)F.
    🔗
    1. Find the value of \(k\text{.}\)
      🔗
    2. When will the pie be \(100^\circ\)F?
      🔗
    🔗
    Solution.
    (a) The kitchen is \(72^\circ\)F, so \(c = 72\text{.}\) The pie starts at \(350^\circ\)F, so \(a = 350 - 72 = 278\) and \(F(x) = 278e^{-kx} + 72\text{.}\) We know \(F(15) = 220\text{,}\) so substitute \(x = 15\) and solve for \(k\text{.}\)
    \begin{align*} 278e^{-15k} + 72 \amp= 220\\ 278e^{-15k} \amp= 148\\ e^{-15k} \amp= \frac{148}{278}\\ -15k \amp= \ln\left(\frac{148}{278}\right)\\ k \amp= \frac{\ln(148/278)}{-15} \approx 0.04203 \end{align*}
    🔗
    Store the unrounded value of \(k\) in your calculator.
    🔗
    (b) Set \(F(x) = 100\) and solve for \(x\text{,}\) using the stored value of \(k\text{.}\)
    \begin{align*} 278e^{-kx} + 72 \amp= 100\\ 278e^{-kx} \amp= 28\\ e^{-kx} \amp= \frac{28}{278}\\ -kx \amp= \ln\left(\frac{28}{278}\right)\\ x \amp= \frac{\ln(28/278)}{-k} \approx 54.62 \end{align*}
    🔗
    The pie will be \(100^\circ\)F after about \(54.62\) minutes.
    🔗
    If you would rather not store \(k\text{,}\) you can substitute its exact value and enter everything at once: \(x = \frac{15\ln(28/278)}{\ln(148/278)} \approx 54.62\text{.}\)
    🔗
    To see why early rounding matters here, suppose we rounded \(k\) to \(0.04\text{.}\) Then \(x = \frac{\ln(28/278)}{-0.04} \approx 57.39\) minutes, which is almost three minutes off.

    Dash pours a cup of tea at \(200^\circ\)F and sets it on a desk in a \(70^\circ\)F room. Let \(F(x)\) be the temperature of the tea \(x\) minutes after it is poured. After \(5\) minutes, the tea is \(170^\circ\)F.
    🔗

    (a)

    Find the value of \(k\text{.}\)
    🔗
    Answer.
    \(k = \frac{\ln(10/13)}{-5} \approx 0.0525\)
    🔗
    🔗
    Solution.
    Here \(c = 70\) and \(a = 200 - 70 = 130\text{,}\) so \(F(x) = 130e^{-kx} + 70\text{.}\) Substitute \(x = 5\) and \(F(5) = 170\text{.}\)
    \begin{align*} 130e^{-5k} + 70 \amp= 170\\ 130e^{-5k} \amp= 100\\ e^{-5k} \amp= \frac{10}{13}\\ -5k \amp= \ln\left(\frac{10}{13}\right)\\ k \amp= \frac{\ln(10/13)}{-5} \approx 0.0525 \end{align*}

    What is the temperature of the tea after \(20\) minutes?
    🔗
    Answer.
    About \(115.52^\circ\)F
    🔗
    🔗
    Solution.
    Using the stored value of \(k\text{,}\) \(F(20) = 130e^{-20k} + 70 \approx 115.52^\circ\)F. There is also an exact way to see this: \(e^{-20k} = \left(e^{-5k}\right)^4 = \left(\frac{10}{13}\right)^4\text{,}\) so \(F(20) = 130\left(\frac{10}{13}\right)^4 + 70 \approx 115.52\text{.}\)

    🔗
    🔗

    \begin{align*} 130e^{-kx} + 70 \amp= 120\\ 130e^{-kx} \amp= 50\\ e^{-kx} \amp= \frac{5}{13}\\ -kx \amp= \ln\left(\frac{5}{13}\right)\\ x \amp= \frac{\ln(5/13)}{-k} \approx 18.21 \end{align*}
    🔗
    The tea is \(120^\circ\)F after about \(18.21\) minutes. This fits with the previous part, since \(120^\circ\)F is warmer than the \(115.52^\circ\)F reading at \(20\) minutes.

    Solve each equation.
    🔗

    (a)

    \(2^{x+3} = 4^x\)
    🔗
    Answer.
    \(x = 3\)
    🔗
    🔗
    Solution.
    Matching bases: \(4^x = (2^2)^x = 2^{2x}\text{,}\) so \(2^{x+3} = 2^{2x}\text{.}\) Then \(x + 3 = 2x\) and \(x = 3\text{.}\)
    🔗
    Using \(\ln\text{:}\) This also works, but takes more algebra.
    \begin{align*} (x + 3)\ln(2) \amp= x\ln(4)\\ x\ln(2) + 3\ln(2) \amp= x\ln(4)\\ 3\ln(2) \amp= x\ln(4) - x\ln(2)\\ 3\ln(2) \amp= x\left(\ln(4) - \ln(2)\right)\\ x \amp= \frac{3\ln(2)}{\ln(4) - \ln(2)} = 3 \end{align*}
    🔗
    The last step uses the exponent rule once more: \(\ln(4) = \ln(2^2) = 2\ln(2)\text{,}\) so the denominator is \(2\ln(2) - \ln(2) = \ln(2)\text{,}\) and \(x = \frac{3\ln(2)}{\ln(2)} = 3\text{.}\) When matching bases is possible, it is usually the faster route.
    🔗
    🔗
    🔗

    \(5^x = 3\)

    Two towns each have 5,000 residents. Town A gains 200 residents each year, and Town B grows by \(3.5\%\) each year.
    🔗

    (a)

    Write a model for the population of each town \(x\) years from now.
    🔗
    Answer.
    Town A: \(L(x) = 5000 + 200x\text{;}\) Town B: \(E(x) = 5000(1.035)^x\)
    🔗
    🔗
    Solution.
    Town A adds the same amount each year, so it is linear with slope \(200\) and vertical intercept \(5000\text{:}\) \(L(x) = 5000 + 200x\text{.}\) Town B multiplies by the same factor each year, so it is exponential with \(a = 5000\) and \(b = 1.035\text{:}\) \(E(x) = 5000(1.035)^x\text{.}\)
    🔗
    🔗
    🔗

    (b)

    When will each town reach 8,000 residents?

    🔗
    🔗
    Solution.
    Town A: \(5000 + 200x = 8000\text{,}\) so \(200x = 3000\) and \(x = 15\) years.
    🔗
    Town B: \(5000(1.035)^x = 8000\text{,}\) so \((1.035)^x = 1.6\) and \(x = \frac{\ln(1.6)}{\ln(1.035)} \approx 13.66\) years.

    🔗
    🔗

After \(9\) years, Town A has 6,800 and Town B has about 6,814. This is also why Town B reaches 8,000 first.

    🔗

    \begin{align*} 75e^{-kx} - 5 \amp= 32\\ 75e^{-kx} \amp= 37\\ e^{-kx} \amp= \frac{37}{75}\\ x \amp= \frac{\ln(37/75)}{-k} \approx 2.77 \end{align*}
    🔗
    The thermometer reads \(32^\circ\)F after about \(2.77\) minutes. This fits with the given reading: the thermometer is at \(40^\circ\)F after \(2\) minutes, so it should take a little longer than \(2\) minutes to reach \(32^\circ\)F.
