    Worksheet Learning Target 5: Inverse Functions
    

    Objectives

    • I can determine whether a function has an inverse with justification and find values of the inverse given input-output pairs of the original.
      🔗
    🔗

    1. Problem 1: Functions Given by a Table.

    Each table below defines a function. Decide whether the function has an inverse function, and justify your answer.
    🔗

    (a)

    \(x\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(f(x)\) \(4\) \(7\) \(2\) \(9\) \(5\)
    Answer.
    Yes. The outputs \(4\text{,}\) \(7\text{,}\) \(2\text{,}\) \(9\text{,}\) and \(5\) are all different, so each output comes from exactly one input. Reversing the table gives a function, so \(f\) has an inverse.
    🔗
    🔗
    🔗

    (b)

    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\)
    \(g(x)\) \(3\) \(6\) \(3\) \(8\) \(1\)
    Answer.
    No. Two different inputs give the same output: \(g(0) = 3\) and \(g(2) = 3\text{.}\) If we reversed the table, the input \(3\) would have to go to both \(0\) and \(2\text{,}\) which is not a function.
    🔗
    🔗
    🔗

    (c)

    \(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
    \(h(x)\) \(4\) \(1\) \(0\) \(1\) \(4\)
    Answer.
    No. The output \(1\) comes from both \(x = -1\) and \(x = 1\text{,}\) and the output \(4\) comes from both \(x = -2\) and \(x = 2\text{.}\) Since some outputs come from more than one input, \(h\) does not have an inverse.
    🔗
    🔗
    🔗

    (d)

    For the function in this problem that has an inverse, find \(f^{-1}(9)\) and \(f^{-1}(2)\text{.}\)
    🔗
    Answer.
    Look for each value in the output row of the table for \(f\text{.}\) Since \(f(4) = 9\text{,}\) we get \(f^{-1}(9) = 4\text{.}\) Since \(f(3) = 2\text{,}\) we get \(f^{-1}(2) = 3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Problem 2: Relationships Given by an Arrow Diagram.

    Each arrow diagram below sends inputs on the left to outputs on the right. Decide whether the relationship is a function. If it is a function, decide whether it has an inverse function. Justify your answers.
    🔗

    (a)

    
    Two ovals, the left labeled Input and the right labeled Output. The inputs are 1, 2, and 3, and the outputs are 5, 8, and 11. Arrows go from 1 to 8, from 2 to 5, and from 3 to 11.
    🔗
    Answer.
    This is a function, since each input has exactly one arrow leaving it. It also has an inverse, since each output has exactly one arrow coming into it. Reversing the arrows sends \(8\) to \(1\text{,}\) \(5\) to \(2\text{,}\) and \(11\) to \(3\text{,}\) which is still a function.
    🔗
    🔗
    🔗

    (b)

    
    Two ovals, the left labeled Input and the right labeled Output. The inputs are 1, 2, and 3, and the outputs are 6 and 9. Arrows go from 1 to 6, from 2 to 6, and from 3 to 9.
    🔗
    Answer.
    This is a function, since each input has exactly one arrow leaving it. It does not have an inverse, because the output \(6\) has two arrows coming into it, from \(1\) and from \(2\text{.}\) Reversing the arrows would send \(6\) to two different places.
    🔗
    🔗
    🔗

    (c)

    
    Two ovals, the left labeled Input and the right labeled Output. The inputs are 1 and 2, and the outputs are 4, 7, and 9. Arrows go from 1 to 4, from 1 to 7, and from 2 to 9.
    🔗
    Answer.
    This is not a function, because the input \(1\) has two arrows leaving it, one to \(4\) and one to \(7\text{.}\) Since it is not a function, the question of an inverse function does not apply.
    🔗
    🔗
    🔗
    🔗

    3. Problem 3: Functions Given by a Graph.

    The graphs of three functions \(p\text{,}\) \(q\text{,}\) and \(r\) are shown below. The horizontal axis shows inputs and the vertical axis shows outputs.
    🔗
    
    The graph of p is a line segment from the point negative four, three to the point four, negative three. It passes through the origin.
    🔗
    
    The graph of q is a U-shaped curve that opens upward. Its lowest point is zero, negative three, and it passes through negative two, negative one and two, negative one before rising to about negative three and a half, three and three and a half, three.
    🔗
    
    The graph of r consists of three connected line segments. The first rises from negative four, negative three to negative one, zero. The second rises more slowly from negative one, zero to two, one. The third rises from two, one to four, four.
    🔗

    (a)

    Does \(p\) have an inverse function? Justify your answer.
    🔗
    Answer.
    Yes. Every horizontal line crosses the graph of \(p\) at most once, so each output comes from exactly one input.
    🔗
    🔗
    🔗

    (b)

    Does \(q\) have an inverse function? Justify your answer.
    🔗
    Answer.
    No. The horizontal line \(y = -1\) crosses the graph twice, at \(x = -2\) and \(x = 2\text{.}\) So \(q(-2) = q(2) = -1\text{,}\) and the output \(-1\) comes from two different inputs.
    🔗
    🔗
    🔗

    (c)

    Does \(r\) have an inverse function? Justify your answer.
    🔗
    Answer.
    Yes. The graph of \(r\) rises the whole way from left to right, so no horizontal line crosses it more than once. Each output comes from exactly one input.
    🔗
    🔗
    🔗

    (d)

    Find \(r^{-1}(0)\) and \(r^{-1}(1)\text{.}\)
    🔗
    Answer.
    To find \(r^{-1}(0)\text{,}\) look for the point on the graph with output \(0\text{.}\) That point is \((-1, 0)\text{,}\) so \(r^{-1}(0) = -1\text{.}\) In the same way, the point \((2, 1)\) is on the graph, so \(r^{-1}(1) = 2\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4. Problem 4: Values of an Inverse.

    The function \(w\) has an inverse function \(w^{-1}\text{.}\) Some values of \(w\) are given in the table below. Find each value.
    🔗
    \(x\) \(-2\) \(0\) \(1\) \(3\) \(6\)
    \(w(x)\) \(7\) \(3\) \(-4\) \(0\) \(1\)

    (a)

    \(w^{-1}(3)\) and \(w^{-1}(0)\)
    🔗
    Answer.
    The inverse takes an output of \(w\) back to its input. Since \(w(0) = 3\text{,}\) we get \(w^{-1}(3) = 0\text{.}\) Since \(w(3) = 0\text{,}\) we get \(w^{-1}(0) = 3\text{.}\) Notice these are not the same, even though the same two numbers appear.
    🔗
    🔗
    🔗

    (b)

    \(w(w^{-1}(7))\) and \(w^{-1}(w(1))\)
    🔗
    Answer.
    Work from the inside out. Since \(w(-2) = 7\text{,}\) we have \(w^{-1}(7) = -2\text{,}\) so \(w(w^{-1}(7)) = w(-2) = 7\text{.}\) Also \(w(1) = -4\text{,}\) so \(w^{-1}(w(1)) = w^{-1}(-4) = 1\text{.}\) In each case, the inverse undoes \(w\) and we get back the number we started with.
    🔗
    🔗
    🔗

    (c)

    Solve \(w(x) = 1\text{.}\)
    🔗
    Answer.
    We need the input that gives an output of \(1\text{.}\) From the table, \(w(6) = 1\text{,}\) so \(x = 6\text{.}\) This is the same as \(w^{-1}(1) = 6\text{.}\)
    🔗
    🔗
    🔗

    (d)

    A different function \(m\) has an inverse, with \(m(5) = 12\) and \(m^{-1}(-3) = 8\text{.}\) Find \(m^{-1}(12)\) and \(m(8)\text{.}\)
    🔗
    Answer.
    Since \(m\) sends \(5\) to \(12\text{,}\) the inverse sends \(12\) back to \(5\text{,}\) so \(m^{-1}(12) = 5\text{.}\) Since \(m^{-1}\) sends \(-3\) to \(8\text{,}\) the function \(m\) sends \(8\) to \(-3\text{,}\) so \(m(8) = -3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    5. Problem 5: Inverse of a Linear Function.

    (a)

    Let \(f(x) = 7x - 11\text{.}\) Find the inverse function \(f^{-1}(x)\text{.}\) You may start by letting \(y = f(x)\text{.}\)
    🔗
    Answer.
    Write \(y = 7x - 11\) and solve for \(x\text{.}\)
    \begin{align*} y \amp= 7x - 11\\ y + 11 \amp= 7x\\ x \amp= \frac{y + 11}{7} \end{align*}
    🔗
    Writing the inverse with \(x\) as its input gives \(f^{-1}(x) = \dfrac{x + 11}{7}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find \(f(2)\text{.}\) Then use your answer to check your formula for \(f^{-1}\text{.}\)
    🔗
    Answer.
    We have \(f(2) = 7(2) - 11 = 3\text{.}\) The inverse should send \(3\) back to \(2\text{,}\) and it does: \(f^{-1}(3) = \dfrac{3 + 11}{7} = \dfrac{14}{7} = 2\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Let \(g(x) = 5 - 2x\text{.}\) Find the inverse function \(g^{-1}(x)\text{.}\)
    🔗
    Answer.
    Write \(y = 5 - 2x\) and solve for \(x\text{.}\)
    \begin{align*} y \amp= 5 - 2x\\ y - 5 \amp= -2x\\ x \amp= \frac{5 - y}{2} \end{align*}
    🔗
    So \(g^{-1}(x) = \dfrac{5 - x}{2}\text{.}\) As a check, \(g(1) = 3\) and \(g^{-1}(3) = \dfrac{5 - 3}{2} = 1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    6. Problem 6: An Inverse in Context.

    A climbing gym charges a flat fee of \(\$40\) to reserve its party room, plus \(\$12\) per guest. The total cost in dollars for \(n\) guests is \(C(n) = 12n + 40\text{.}\)
    🔗

    (a)

    Find \(C(10)\) and explain what it means in a full sentence.
    🔗
    Answer.
    \(C(10) = 12(10) + 40 = 160\text{.}\) A party with \(10\) guests costs \(\$160\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find a formula for \(C^{-1}\text{.}\) What are the input and the output of \(C^{-1}\text{?}\) Include units.
    🔗
    Answer.
    Let \(c = 12n + 40\) be the cost and solve for \(n\text{.}\)
    \begin{align*} c - 40 \amp= 12n\\ n \amp= \frac{c - 40}{12} \end{align*}
    🔗
    So \(C^{-1}(c) = \dfrac{c - 40}{12}\text{.}\) The input of \(C^{-1}\) is a total cost in dollars, and the output is a number of guests.
    🔗
    🔗
    🔗

    (c)

    Find \(C^{-1}(280)\) and explain what it means in a full sentence.
    🔗
    Answer.
    \(C^{-1}(280) = \dfrac{280 - 40}{12} = \dfrac{240}{12} = 20\text{.}\) A party that costs \(\$280\) has \(20\) guests.
    🔗
    🔗
    🔗
    🔗

    7. Problem 7: Creating Examples.

    (a)

    On the grid below, sketch the graph of a function that does have an inverse. Assume the horizontal axis shows inputs and the vertical axis shows outputs, as usual.
    🔗
    
    A blank coordinate grid with x and y axes, running from negative five to five in each direction.
    🔗
    Answer.
    Answers will vary. Any graph that always rises or always falls works, such as the line \(y = 2x + 1\text{.}\) Every vertical line crosses it at most once, so it is a function, and every horizontal line crosses it at most once, so it has an inverse.
    🔗
    🔗
    🔗

    (b)

    Complete the table so that it defines a function that does not have an inverse.
    🔗
    \(x\)
    \(f(x)\)
    Answer.
    Answers will vary. One example uses the inputs \(1\text{,}\) \(2\text{,}\) \(3\text{,}\) \(4\text{,}\) \(5\) with the outputs \(6\text{,}\) \(2\text{,}\) \(6\text{,}\) \(0\text{,}\) \(9\text{.}\) The inputs are all different, so it is a function.
    🔗
    🔗
    🔗

    (c)

    Explain why your table is a function, but does not have an inverse.
    🔗
    Answer.
    For the example above, each input appears only once, so each input has exactly one output. But the output \(6\) comes from two inputs, \(1\) and \(3\text{,}\) so reversing the table would send \(6\) to two different values.
