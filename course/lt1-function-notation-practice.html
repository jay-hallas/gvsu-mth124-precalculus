    Worksheet Learning Target 1: Function Notation and Functions
    

    Objectives

    • I can use function notation, find and simplify the output of a function given an input, and find an input that produces a given output; I can do this for functions given by a formula, a table, and a graph.
      🔗
    🔗

    1. Evaluating a Function Given by a Formula.

    Function notation gives us a convenient way to describe the output of a function corresponding to a particular input.
    🔗

    (a)

    Suppose $\displaystyle g(x)=\frac{20}{2x+1}$. What is $g(2)$?
    🔗
    Answer.
    Substitute $2$ for $x$:
    🔗
    \[ g(2)=\frac{20}{2(2)+1} =\frac{20}{5} =4. \]
    🔗
    Therefore, $\boxed{g(2)=4}$.
    🔗
    🔗
    🔗
    🔗

    2. Evaluate and Simplify.

    (a)

    Suppose $\displaystyle f(x)=\frac{x^2-9}{x-3}$. Find and simplify $f(5)$.
    🔗
    Answer.
    Substitute $5$ for $x$:
    🔗
    \[ f(5)=\frac{5^2-9}{5-3} =\frac{25-9}{2} =\frac{16}{2} =8. \]
    🔗
    Therefore, $\boxed{f(5)=8}$.
    🔗
    🔗
    🔗
    🔗

    3. Finding an Input.

    (a)

    Suppose $\displaystyle h(x)=4x-7$. Find the input $x$ for which $h(x)=13$.
    🔗
    Answer.
    We want the output to be $13$, so solve \[ 4x-7=13. \]
    🔗
    Add $7$ to both sides: \[ 4x=20. \] Divide by $4$: \[ x=5. \]
    🔗
    Therefore, the input that produces an output of $13$ is $\boxed{5}$.
    🔗
    🔗
    🔗
    🔗

    4. Can More Than One Input Produce the Same Output?

    (a)

    Suppose $\displaystyle p(x)=(x+1)^2$. Find all inputs that produce an output of $9$.
    🔗
    Answer.
    We want \[ p(x)=9, \] so solve \[ (x+1)^2=9. \]
    🔗
    Taking the square root gives \[ x+1=\pm 3. \] Therefore, \[ x=2 \quad\text{or}\quad x=-4. \]
    🔗
    Both $2$ and $-4$ produce an output of $9$. Thus the inputs are $\boxed{x=2\text{ and }x=-4}$.
    🔗
    🔗
    🔗
    🔗

    5. Is This Rule a Function?

    A function assigns exactly one output to each input.
    🔗

    (a)

    Consider the rule defined by the table below.
    🔗
    Can this rule be a function? Explain why or why not.
    🔗
    Answer.
    No. This rule cannot be a function because the input $x=2$ is paired with two different outputs, $105$ and $170$.
    🔗
    A function must assign exactly one output to each input.
    🔗
    🔗
    🔗
    🔗

    6. A Real-World Function.

    (a)

    Consider a rule that sends a paper book to the number of pages in it. Do you think this could be a function? Explain why or why not.
    🔗
    Answer.
    Yes. This could be a function because each particular paper book has exactly one number of pages.
    🔗
    For example, a particular book might have $320$ pages. Although two different books may have the same number of pages, that does not prevent the rule from being a function. What matters is that one input does not produce two different outputs.
    🔗
    🔗
    🔗
    🔗

    7. Interpreting Function Notation.

    (a)

    Suppose water is being drained from a pool and $V(t)$ is the volume of water, in cubic feet, $t$ hours after we started draining the pool. Explain in writing what $V(4)=3000$ means.
    🔗
    Answer.
    The statement $V(4)=3000$ means that 4 hours after we started draining the pool, the volume of water in the pool is 3000 cubic feet.
    🔗
    🔗
    🔗
    🔗

    8. Evaluating a Function from a Table.

    (a)

    The table gives values for a function $f$.
    🔗
    1. Find $f(-1)$.
      🔗
    2. Find $f(2)$.
      🔗
    3. Find all inputs that produce an output of $5$.
      🔗
    🔗
    Answer.
    Read the output corresponding to each requested input directly from the table.
    🔗
    \[ f(-1)=2 \] and \[ f(2)=5. \]
    🔗
    An output of $5$ occurs when $x=-2$ and when $x=2$. Thus the inputs that produce an output of $5$ are $\boxed{-2\text{ and }2}$.
    🔗
    🔗
    🔗
    🔗

    9. Evaluating a Function from a Graph.

    (a)

    The graph below represents a function $f$.
    🔗
    
    A coordinate graph with horizontal axis labeled $x$ and vertical axis labeled $f(x)$. Connected line segments form a peaked and valley-shaped graph through the points $(-4,1)$, $(-2,3)$, $(0,0)$, $(2,3)$, and $(4,1)$.
    🔗
    Use the graph to answer the following questions.
    🔗
    1. Find $f(-2)$.
      🔗
    2. Find $f(0)$.
      🔗
    3. Find $f(2)$.
      🔗
    4. Find all inputs that produce an output of $1$.
      🔗
    🔗
    Answer.
    Reading the corresponding output values from the graph:
    🔗
    \[ f(-2)=3, \qquad f(0)=0, \qquad f(2)=3. \]
    🔗
    The graph has output $1$ when $x=-4$ and when $x=4$. Therefore, the inputs producing an output of $1$ are $\boxed{-4\text{ and }4}$.
    🔗
    🔗

    10. Recognizing a Function from a Graph.

    (a)

    Give an example of a graph that is not a function if the horizontal axis represents input values and the vertical axis represents output values. Explain how you know the graph is not a function.
    🔗
    Hint: Think about whether one input value could have more than one output.
    🔗
    Answer.
    One example is a circle. A vertical line through the circle usually intersects the graph at two points, which means that the same input value would have two different outputs. Therefore, the graph does not represent a function.
    🔗
    
    A coordinate graph containing a circle centered at the origin. A vertical line through the center intersects the circle at two points, demonstrating that the graph does not represent a function.
