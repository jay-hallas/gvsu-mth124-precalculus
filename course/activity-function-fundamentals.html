    Worksheet Activity: Function Fundamentals
    

    1. Function Definition and Tables.

    A function is a rule that assigns to each input exactly one output. The set of all possible inputs is called the domain, and the set of all corresponding outputs is called the range. Two different inputs are allowed to share an output; a single input is never allowed to have two outputs. When working in context, identifying the units of the input and output is just as important as the arithmetic.
    🔗

    (a)

    Determine whether the following table can represent a function. Make a brief note explaining why or why not.
    🔗
    \(x\) \(10\) \(-2\) \(2\) \(8\) \(14\)
    \(y\) \(65\) \(50\) \(50\) \(26\) \(17\)
    Solution.
    Yes, this table can represent a function. We check the inputs (the \(x\)-values) to ensure that each one is assigned to exactly one output. The input \(-2\) maps to \(50\text{,}\) and the input \(2\) also maps to \(50\text{.}\) It is perfectly valid for two different inputs to share the same output. Because no single input is assigned multiple different outputs, the defining rule of a function is satisfied.
    🔗
    🔗
    🔗

    (b)

    Determine whether the following table can represent a function. Make a brief note explaining why or why not.
    🔗
    \(x\) \(5\) \(0\) \(-3\) \(3\) \(5\)
    \(y\) \(-1\) \(5\) \(30\) \(-15\) \(-3\)
    Solution.
    No, this table cannot represent a function. If we examine the inputs, we see that \(x = 5\) appears twice in the domain row. In the first instance, the input \(5\) is assigned an output of \(-1\text{.}\) In the second instance, the same input \(5\) is assigned an output of \(-3\text{.}\) Because a single input is mapping to two distinct outputs, this relationship violates the strict definition of a function.
    🔗
    🔗
    🔗

    (c)

    Determine whether the following table can represent a function. Make a brief note explaining why or why not.
    🔗
    \(x\) \(-4\) \(-1\) \(0\) \(1\) \(4\)
    \(y\) \(7\) \(7\) \(7\) \(7\) \(7\)
    Solution.
    Yes, this table can represent a function. Every input in the top row has exactly one output associated with it. The fact that every input produces the identical output of \(7\) means this represents a constant function. The definition of a function only prohibits one input from pointing to multiple outputs; it places no restriction on how many inputs can point to the same output.
    🔗
    🔗

    2. Evaluating from a Table.

    Consider the function \(g(x)\) defined by the following table:
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(g(x)\) \(-6\) \(11\) \(17\) \(-5\) \(17\) \(0\)

    (a)

    Determine \(g(0)\text{.}\)
    🔗
    Solution.
    The notation \(g(0)\) tells us to find the output when the input is \(0\text{.}\) Locating \(0\) in the \(x\) row, we read the corresponding value directly below it in the \(g(x)\) row. Therefore, \(g(0) = -6\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find all \(x\) values such that \(g(x)=17\text{.}\)
    🔗
    Solution.
    The equation \(g(x) = 17\) provides the output and asks us to work backwards to find the input(s). Scanning the \(g(x)\) row for the value \(17\text{,}\) we see it appears twice. Reading the corresponding inputs in the top row above these values yields \(x = 2\) and \(x = 4\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find all \(x\) values such that \(g(x)=0\text{.}\) Is this the same question as finding \(g(0)\text{?}\) Explain the difference in your own words.
    🔗
    Solution.
    Scanning the \(g(x)\) row for the output \(0\text{,}\) we find it in the final column. Reading up to the input row, the corresponding input is \(x = 5\text{.}\)
    🔗
    This is an entirely different operation from finding \(g(0)\text{.}\) The expression \(g(0)\) puts \(0\) in the input slot, meaning we start at the top of the table and read downward. The equation \(g(x) = 0\) puts \(0\) in the output slot, meaning we start at the bottom of the table and read upward to find all matching inputs.
    🔗
    🔗
    🔗

    3. Evaluating Symbolic Functions.

    To evaluate a function given by a formula, replace every occurrence of the input variable with the value you were given, wrapping negative inputs in parentheses. Then simplify one operation at a time. If the formula contains a fraction or a square root, check whether the input is even allowed before you simplify.
    🔗

    (a)

    Let \(\displaystyle f(t) = -4t + \frac{20}{3t+16}\text{.}\) Evaluate \(f(-2)\) and show your step-by-step simplification.
    🔗
    Solution.
    First, substitute \(-2\) for every instance of \(t\) in the formula, making sure to use parentheses around the negative value:
    \begin{align*} f(-2) \amp= -4(-2) + \frac{20}{3(-2) + 16} \end{align*}
    Next, perform the multiplications in the first term and in the denominator:
    \begin{align*} \amp= 8 + \frac{20}{-6 + 16} \end{align*}
    Simplify the denominator, then reduce the fraction:
    \begin{align*} \amp= 8 + \frac{20}{10}\\ \amp= 8 + 2 \end{align*}
    Finally, combine the terms: \(f(-2) = 10\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4. Quadratic Function Evaluation.

    Let \(g(x) = 3x^2 - 5x + 2\text{.}\)
    🔗

    (a)

    Determine \(g(2)\text{.}\)
    🔗
    Solution.
    Substitute \(2\) for \(x\) and follow the order of operations, ensuring exponents are applied before multiplication:
    \begin{align*} g(2) \amp= 3(2)^2 - 5(2) + 2\\ \amp= 3(4) - 10 + 2\\ \amp= 12 - 10 + 2\\ \amp= 4 \end{align*}
    🔗
    🔗
    🔗

    (b)

    Determine \(g(-3)\text{.}\)
    🔗
    Solution.
    Substitute \(-3\) for \(x\text{,}\) being particularly careful with the signs when squaring a negative number and when multiplying two negative values:
    \begin{align*} g(-3) \amp= 3(-3)^2 - 5(-3) + 2\\ \amp= 3(9) + 15 + 2\\ \amp= 27 + 15 + 2\\ \amp= 44 \end{align*}
    🔗
    🔗
    🔗
    🔗

    5. Rational Functions and Domain Restrictions.

    Let \(\displaystyle h(x) = \frac{x+5}{x^2-9}\text{.}\)
    🔗

    (a)

    Determine \(h(-1)\text{,}\) writing your answer as a simplified fraction.
    🔗
    Solution.
    Substitute \(-1\) into both the numerator and denominator:
    \begin{align*} h(-1) \amp= \frac{(-1)+5}{(-1)^2 - 9}\\ \amp= \frac{4}{1 - 9}\\ \amp= \frac{4}{-8}\\ \amp= -\frac{1}{2} \end{align*}
    🔗
    🔗
    🔗

    (b)

    Are there any input values that must be excluded from the domain of \(h\text{?}\) If so, list them and explain what goes wrong there.
    🔗
    Solution.
    Yes. For a rational function, any input that makes the denominator equal to zero must be excluded from the domain, because division by zero is mathematically undefined. To find these restricted values, set the denominator equal to zero and solve for \(x\text{:}\)
    \begin{align*} x^2 - 9 \amp= 0\\ (x - 3)(x + 3) \amp= 0 \end{align*}
    This gives the solutions \(x = 3\) and \(x = -3\text{.}\) Both of these inputs will cause division by zero, so they must be entirely excluded from the domain of \(h\text{.}\)
    🔗
    🔗
    🔗
    🔗

    6. Radical Function Evaluation.

    (a)

    Let \(p(x) = \sqrt{2x+7} - x\text{.}\) Determine \(p(1)\) and \(p(-3)\text{.}\)
    🔗
    Solution.
    For \(p(1)\text{,}\) substitute \(1\) for \(x\text{:}\)
    \begin{align*} p(1) \amp= \sqrt{2(1)+7} - 1\\ \amp= \sqrt{2+7} - 1\\ \amp= \sqrt{9} - 1\\ \amp= 3 - 1 = 2 \end{align*}
    For \(p(-3)\text{,}\) substitute \(-3\) for \(x\text{:}\)
    \begin{align*} p(-3) \amp= \sqrt{2(-3)+7} - (-3)\\ \amp= \sqrt{-6+7} + 3\\ \amp= \sqrt{1} + 3\\ \amp= 1 + 3 = 4 \end{align*}
    🔗
    🔗
    🔗
    🔗

    7. Expression Substitution.

    (a)

    Let \(f(x) = x^2 - 4x\text{.}\) Determine \(f(x+1)\) and simplify your answer completely. (Substitute the entire expression \(x+1\) everywhere you see an \(x\text{.}\))
    🔗
    Solution.
    To evaluate \(f(x+1)\text{,}\) treat the entire quantity \((x+1)\) as a single input block and place it into every slot where an \(x\) appears in the original formula:
    \begin{align*} f(x+1) \amp= (x+1)^2 - 4(x+1) \end{align*}
    Next, expand the squared binomial carefully. A common pitfall is to write \(x^2 + 1\text{,}\) but the correct expansion requires distributing: \((x+1)(x+1) = x^2 + 1x + 1x + 1 = x^2 + 2x + 1\text{.}\) Also, be sure to distribute the \(-4\) through the second term:
    \begin{align*} \amp= (x^2 + 2x + 1) - 4x - 4 \end{align*}
    Finally, combine the like terms (\(2x\) and \(-4x\text{,}\) as well as \(1\) and \(-4\)) to fully simplify:
    \begin{align*} \amp= x^2 - 2x - 3 \end{align*}
    🔗
    🔗
    🔗
    🔗

    8. Evaluating from a Graph.

    Consider a function \(f(x)\) defined by the piecewise linear graph below.
    🔗
    
    A piecewise linear graph made of three connected segments. It begins at (-4,-2), rises to a peak at (-2,2), drops back down to a valley at (2,-2), and rises again to end at (4,2).
    🔗

    (a)

    Determine \(f(1)\text{.}\)
    🔗
    Solution.
    Locate the input \(x = 1\) on the horizontal axis and trace vertically to the graph. The graph passes through the point \((1, -1)\) on the falling segment. The output is the \(y\)-coordinate, so \(f(1) = -1\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find all \(x\) values such that \(f(x)=0\text{.}\)
    🔗
    Solution.
    We are looking for all points where the graph is at a height of zero (meaning it intersects the \(x\)-axis). Examining the grid, the graph crosses the horizontal axis at three distinct locations: midway up the first rising segment at \((-3,0)\text{,}\) precisely at the origin \((0,0)\text{,}\) and midway up the final rising segment at \((3,0)\text{.}\) Therefore, the inputs are \(x = -3\text{,}\) \(x = 0\text{,}\) and \(x = 3\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find all \(x\) values such that \(f(x)=2\text{.}\)
    🔗
    Solution.
    We must locate all points on the graph that sit at a height of \(y = 2\text{.}\) Scanning horizontally across the grid at that level, the graph reaches a height of \(2\) exactly twice: at the peak corner point \((-2, 2)\text{,}\) and at the final endpoint on the far right at \((4, 2)\text{.}\) Therefore, the inputs are \(x = -2\) and \(x = 4\text{.}\)
    🔗
    🔗

    9. Graphical Function Identification.

    (a)

    Two of the graphs below represent functions and two do not. Assume the horizontal axis corresponds to inputs (\(x\)) and the vertical axis corresponds to outputs (\(y\)). Identify the two that are not functions, and explain how you decided.
    🔗
    Solution.
    Graph B and Graph D do not represent functions. We can determine this by applying the Vertical Line Test. In a function graph, every vertical line represents a specific input \(x\text{,}\) and if a line crosses the graph more than once, it means that single input is yielding multiple different outputs.
    🔗
    In Graph B (the sideways parabola), a vertical line drawn at \(x = 2\) will intersect the graph at two distinct points: \((2, 2)\) and \((2, -2)\text{.}\) Because the input \(2\) has two outputs, it fails to be a function.
    🔗
    In Graph D (the circle), a vertical line drawn exactly on the \(y\)-axis (where \(x = 0\)) will hit the graph at both \((0, 2)\) and \((0, -2)\text{.}\) Again, a single input yields multiple outputs, so it is not a function.
    🔗
    Graphs A and C successfully pass the vertical line test. (Note for Graph C: sharp corners are entirely allowed in functions, provided there is no vertical overlap).

    10. Functions in Context: Laptop Battery.

    A statement like \(f(3) = 12\) carries three pieces of information: the input value, the output value, and the units attached to each. A good interpretation is a full sentence that mentions all three and never uses the letters \(f\text{,}\) \(x\text{,}\) or \(t\text{.}\)
    🔗
    A laptop is unplugged from the wall and begins running on battery power. The remaining battery charge, \(B\) (measured as a percentage), is a function of the time \(t\) (measured in hours) since the laptop was unplugged. Let \(B = f(t)\text{.}\)
    🔗

    (a)

    Identify the input and output variables, making sure to state their specific units.
    🔗
    Solution.
    The input variable is time \(t\text{,}\) and its units are hours. The output variable is the remaining battery charge \(B\text{,}\) and its units are percent.
    🔗
    🔗
    🔗

    (b)

    Interpret the meaning of the statement \(f(2.5) = 40\) in the context of this scenario.
    🔗
    Solution.
    Two and a half hours after the laptop was unplugged from the wall, the remaining battery charge has decreased to 40 percent.
    🔗
    🔗
    🔗

    (c)

    If we were to calculate the change in battery charge divided by the change in time, what would the units of this new value be? Briefly explain what this rate represents in this context.
    🔗
    Solution.
    The units of this rate would be percent per hour (change in output units divided by change in input units). Conceptually, this rate represents the average speed at which the laptop is consuming battery power over a given time interval. Because the battery is draining, we would expect this calculated rate of change to be a negative number.
    🔗
    🔗
    🔗

    11. Functions in Context: Coffee Temperature.

    A cup of coffee is poured and left sitting on a desk. Its temperature \(C\) (measured in degrees Fahrenheit) is a function of the number of minutes \(m\) since it was poured. Let \(C = h(m)\text{.}\)
    🔗

    (a)

    Identify the input and output variables, making sure to state their specific units.
    🔗
    Solution.
    The input variable is time \(m\text{,}\) and its units are minutes. The output variable is the temperature of the coffee \(C\text{,}\) and its units are degrees Fahrenheit.
    🔗
    🔗
    🔗

    (b)

    Interpret the meaning of the statement \(h(10) = 145\) in the context of this scenario.
    🔗
    Solution.
    Ten minutes after the cup of coffee was poured, it has cooled to a temperature of exactly 145 degrees Fahrenheit.
    🔗
    🔗
    🔗

    (c)

    Explain what the equation \(h(m) = 100\) is asking, and describe what a solution to that equation would tell you about the coffee. How is this different from the question in part (b)?
    🔗
    Solution.
    This equation is asking us to find the specific time (or times) at which the coffee’s temperature reaches exactly 100 degrees Fahrenheit. If we were to solve the equation, the resulting number would tell us how many minutes the coffee had been sitting on the desk before it hit that temperature threshold.
    🔗
    The difference between this and part (b) is the direction of the evaluation. In part (b), the input time (\(10\) minutes) was provided to us, and we evaluated the function to report the output temperature. Here, the output temperature (\(100\) degrees) is the known value, and we are working backwards to solve for the unknown input time.
