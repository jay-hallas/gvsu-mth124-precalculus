    Worksheet Learning Target 7: Transformed Sine and Cosine Functions
    

    Objectives

    • I can find the amplitude, period, and midline of a transformed version of the basic sine or cosine function; and I can find the formulas for transformed versions of the basic sine or cosine function that have certain described properties.
      🔗
    🔗

    1. Problem 1: Features from a Formula.

    Let \(\displaystyle f(x) = 6\cos\left(\frac{\pi}{8}x\right) + 5\text{.}\)
    🔗

    (a)

    Find the amplitude.
    🔗
    Answer.
    The amplitude is the absolute value of the number in front of cosine, so the amplitude is \(|6| = 6\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find the equation of the midline.
    🔗
    Answer.
    The constant added at the end shifts the wave up \(5\) units, so the midline is \(y = 5\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find the period. Show your work.
    🔗
    Answer.
    Here \(B = \frac{\pi}{8}\text{,}\) so
    \begin{align*} \text{period} \amp= \frac{2\pi}{\pi/8} = 2\pi \cdot \frac{8}{\pi} = 16 \end{align*}
    🔗
    The period is \(16\text{.}\) A common mistake is to give \(\frac{\pi}{8}\) or \(8\) as the period.
    🔗
    🔗
    🔗

    (d)

    What are the maximum and minimum values of \(f\text{?}\)
    🔗
    Answer.
    The wave goes \(6\) units above and below the midline. The maximum is \(5 + 6 = 11\) and the minimum is \(5 - 6 = -1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Problem 2: A Flipped Wave.

    Let \(\displaystyle g(x) = -\frac{5}{2}\sin\left(\frac{2\pi}{9}x\right) - 3\text{.}\)
    🔗

    (a)

    Find the amplitude.
    🔗
    Answer.
    The amplitude is \(\left|-\frac{5}{2}\right| = \frac{5}{2}\text{.}\) The negative sign flips the wave upside down, but the amplitude is still positive.
    🔗
    🔗
    🔗

    (b)

    Find the equation of the midline.
    🔗
    Answer.
    The midline is \(y = -3\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find the period. Show your work.
    🔗
    Answer.
    Here \(B = \frac{2\pi}{9}\text{,}\) so
    \begin{align*} \text{period} \amp= \frac{2\pi}{2\pi/9} = 2\pi \cdot \frac{9}{2\pi} = 9 \end{align*}
    🔗
    The period is \(9\text{.}\)
    🔗
    🔗
    🔗

    (d)

    What are the maximum and minimum values of \(g\text{?}\)
    🔗
    Answer.
    The maximum is \(-3 + \frac{5}{2} = -\frac{1}{2}\) and the minimum is \(-3 - \frac{5}{2} = -\frac{11}{2}\text{.}\) Even though the wave is flipped, the maximum and minimum are still found by adding and subtracting the amplitude from the midline.
    🔗
    🔗
    🔗
    🔗

    3. Problem 3: A Ferris Wheel.

    A Ferris wheel is \(44\) meters in diameter and is boarded from a platform that is \(5\) meters above the ground. The six o’clock position on the wheel is level with the loading platform. The wheel completes one full revolution in \(14\) minutes. The function \(h = f(t)\) gives your height in meters above the ground \(t\) minutes after the wheel begins to turn.
    🔗

    (a)

    Write an equation for \(h = f(t)\text{.}\)
    🔗
    Answer.
    You board at the bottom of the wheel, so you start at a minimum and the base model is \(-\cos\text{.}\) The radius is \(\frac{44}{2} = 22\text{,}\) so the amplitude is \(22\text{.}\) The center of the wheel is \(5 + 22 = 27\) meters above the ground, so the midline is \(h = 27\text{.}\) The period is \(14\) minutes.
    \begin{align*} \frac{2\pi}{B} \amp= 14\\ B \amp= \frac{2\pi}{14} = \frac{\pi}{7} \end{align*}
    🔗
    The model is \(f(t) = -22\cos\left(\frac{\pi}{7}t\right) + 27\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Use your equation to find \(f(0)\) and \(f(7)\text{.}\) Explain why these values make sense.
    🔗
    Answer.
    \(f(0) = -22\cos(0) + 27 = -22 + 27 = 5\text{,}\) which is the height of the platform where you board. \(f(7) = -22\cos(\pi) + 27 = 22 + 27 = 49\text{.}\) After half a revolution you are at the top of the wheel, which is \(5 + 44 = 49\) meters above the ground.
    🔗
    🔗
    🔗
    🔗

    4. Problem 4: A Model from Data.

    The table below gives values of a sinusoidal function.
    🔗
    \(x\) \(0\) \(3\) \(6\) \(9\) \(12\) \(15\) \(18\)
    \(y\) \(-3\) \(1\) \(-3\) \(-7\) \(-3\) \(1\) \(-3\)

    (a)

    Find a sinusoidal function to match the data.
    🔗
    Answer.
    The largest value is \(1\) and the smallest is \(-7\text{.}\)
    \begin{align*} \text{midline: } y \amp= \frac{1 + (-7)}{2} = -3\\ \text{amplitude} \amp= \frac{1 - (-7)}{2} = 4 \end{align*}
    🔗
    At \(x = 0\) the value \(-3\) is on the midline, and the next value \(1\) is larger, so the data starts on the midline going up. The base model is \(\sin\text{.}\) The data is back on the midline going up at \(x = 12\text{,}\) so the period is \(12\) and \(B = \frac{2\pi}{12} = \frac{\pi}{6}\text{.}\) The model is \(f(x) = 4\sin\left(\frac{\pi}{6}x\right) - 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Check your function using one value from the table that is not on the midline.
    🔗
    Answer.
    Using \(x = 9\text{:}\) \(f(9) = 4\sin\left(\frac{3\pi}{2}\right) - 3 = 4(-1) - 3 = -7\text{,}\) which matches the table.
    🔗
    🔗
    🔗
    🔗

    5. Problem 5: A Water Wheel.

    A water wheel at an old mill has a diameter of \(8\) meters, and its center is \(3\) meters above the surface of the river. One bucket on the wheel starts level with the center of the wheel and is moving upward. The wheel completes one full turn every \(20\) seconds. The function \(h = f(t)\) gives the bucket’s height in meters above the water \(t\) seconds after we start watching.
    🔗

    (a)

    Write an equation for \(h = f(t)\text{.}\)
    🔗
    Answer.
    The bucket starts at the height of the center and is moving up, so it starts on the midline going up. The base model is \(\sin\text{.}\) The radius is \(\frac{8}{2} = 4\text{,}\) so the amplitude is \(4\text{,}\) and the midline is \(h = 3\text{.}\) The period is \(20\) seconds.
    \begin{align*} \frac{2\pi}{B} \amp= 20\\ B \amp= \frac{2\pi}{20} = \frac{\pi}{10} \end{align*}
    🔗
    The model is \(f(t) = 4\sin\left(\frac{\pi}{10}t\right) + 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    What is the minimum value of \(f\text{?}\) What does it tell you about the bucket?
    🔗
    Answer.
    The minimum is \(3 - 4 = -1\text{.}\) At the bottom of each turn the bucket is \(1\) meter below the surface of the river, which is how it fills with water.
