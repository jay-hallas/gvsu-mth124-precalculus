    Worksheet Learning Target: Composition of Functions
    

    Objectives

    • I can find and simplify values of the composition of two functions; I can do this for functions given by a formula, a table, and a graph.
      🔗
    🔗

    1. Problem 1: Functions Given by a Table.

    The functions \(f\) and \(g\) are defined by the table below. Find each value if it exists. If a value does not exist, briefly explain why.
    🔗
    \(x\) \(0\) \(1\) \(2\) \(3\) \(4\) \(5\)
    \(f(x)\) \(0\) \(5\) \(3\) \(7\) \(2\) \(6\)
    \(g(x)\) \(4\) \(2\) \(1\) \(3\) \(5\) \(1\)

    (a)

    \(f(g(0))\)
    🔗
    Answer.
    Work from the inside out. From the table, \(g(0) = 4\text{,}\) so \(f(g(0)) = f(4) = 2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    \(f(g(3))\)
    🔗
    Answer.
    From the table, \(g(3) = 3\text{,}\) so \(f(g(3)) = f(3) = 7\text{.}\)
    🔗
    🔗
    🔗

    (c)

    \(f(g(4))\)
    🔗
    Answer.
    From the table, \(g(4) = 5\text{,}\) so \(f(g(4)) = f(5) = 6\text{.}\)
    🔗
    🔗
    🔗

    (d)

    \(g(f(5))\)
    🔗
    Answer.
    From the table, \(f(5) = 6\text{,}\) so \(g(f(5)) = g(6)\text{.}\) The input \(6\) does not appear in the table, so we have no value for \(g(6)\text{.}\) The value \(g(f(5))\) does not exist.
    🔗
    🔗
    🔗

    (e)

    \(g(f(2))\)
    🔗
    Answer.
    From the table, \(f(2) = 3\text{,}\) so \(g(f(2)) = g(3) = 3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Problem 2: Functions Given by a Formula.

    Let \(f(x) = x^2 - 4\) and \(g(x) = 3x + 1\text{.}\)
    🔗

    (a)

    Find and simplify \(f(g(x))\text{.}\)
    🔗
    Answer.
    Substitute the whole expression \(3x+1\) for the input of \(f\text{,}\) then expand.
    \begin{align*} f(g(x)) \amp= f(3x+1)\\ \amp= (3x+1)^2 - 4\\ \amp= 9x^2 + 6x + 1 - 4\\ \amp= 9x^2 + 6x - 3 \end{align*}
    🔗
    Note that \((3x+1)^2\) is not \(9x^2 + 1\text{;}\) the middle term \(6x\) comes from multiplying \((3x+1)(3x+1)\) out completely.
    🔗
    🔗
    🔗

    (b)

    Find and simplify \(g(f(x))\text{.}\)
    🔗
    Answer.
    Substitute the whole expression \(x^2 - 4\) for the input of \(g\text{.}\)
    \begin{align*} g(f(x)) \amp= g(x^2-4)\\ \amp= 3(x^2-4) + 1\\ \amp= 3x^2 - 12 + 1\\ \amp= 3x^2 - 11 \end{align*}
    🔗
    🔗
    🔗

    (c)

    Find \(f(g(-2))\) and \(g(f(-2))\text{.}\) What do your answers tell you about the order of composition?
    🔗
    Answer.
    Work from the inside out for each one.
    \begin{align*} g(-2) \amp= 3(-2) + 1 = -5\\ f(g(-2)) \amp= f(-5) = (-5)^2 - 4 = 21\\ f(-2) \amp= (-2)^2 - 4 = 0\\ g(f(-2)) \amp= g(0) = 3(0) + 1 = 1 \end{align*}
    🔗
    We get \(f(g(-2)) = 21\) and \(g(f(-2)) = 1\text{.}\) The two answers are different, so the order matters; \(f(g(x))\) and \(g(f(x))\) are usually different functions. As a check, the formula from the first part gives \(9(-2)^2 + 6(-2) - 3 = 21\text{.}\)
    🔗
    🔗
    🔗
    🔗

    3. Problem 3: Functions Given by a Graph.

    The graph of \(f\) is shown on the left and the graph of \(g\) is shown on the right.
    🔗
    
    The graph of f consists of three connected line segments. The first segment rises from the point negative four, negative three to the point negative one, three. The second segment is horizontal, running from negative one, three to the point two, three. The third segment falls from two, three to the point four, negative one.
    🔗
    
    The graph of g consists of two connected line segments. The first segment rises from the point negative four, negative two to the point zero, two. The second segment falls from zero, two to the point four, negative two.
    🔗

    (a)

    Find \(f(g(-2))\text{.}\)
    🔗
    Answer.
    Reading the graph of \(g\text{,}\) \(g(-2) = 0\text{.}\) Reading the graph of \(f\text{,}\) \(f(0) = 3\text{.}\) So \(f(g(-2)) = 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find \(g(f(3))\text{.}\)
    🔗
    Answer.
    Reading the graph of \(f\text{,}\) \(f(3) = 1\text{.}\) Reading the graph of \(g\text{,}\) \(g(1) = 1\text{.}\) So \(g(f(3)) = 1\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find \(g(g(4))\text{.}\)
    🔗
    Answer.
    Both steps use the graph of \(g\text{.}\) First \(g(4) = -2\text{,}\) and then \(g(-2) = 0\text{.}\) So \(g(g(4)) = 0\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Find \(f(g(0))\) and \(g(f(0))\text{.}\) Explain which graph you read first for each one.
    🔗
    Answer.
    For \(f(g(0))\text{,}\) the inside function is \(g\text{,}\) so read the graph of \(g\) first: \(g(0) = 2\text{,}\) and then \(f(2) = 3\text{.}\) So \(f(g(0)) = 3\text{.}\)
    🔗
    For \(g(f(0))\text{,}\) the inside function is \(f\text{,}\) so read the graph of \(f\) first: \(f(0) = 3\text{,}\) and then \(g(3) = -1\text{.}\) So \(g(f(0)) = -1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4. Problem 4: Mixing a Formula and a Table.

    Let \(r(x) = x^2 - 3\text{,}\) and let \(s\) be the function defined by the table below. Find each value if it exists. If a value does not exist, briefly explain why.
    🔗
    \(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\) \(3\)
    \(s(x)\) \(4\) \(0\) \(-1\) \(3\) \(6\) \(2\)

    (a)

    \(s(r(2))\)
    🔗
    Answer.
    Use the formula first: \(r(2) = 2^2 - 3 = 1\text{.}\) Then use the table: \(s(1) = 3\text{.}\) So \(s(r(2)) = 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    \(r(s(-1))\)
    🔗
    Answer.
    Use the table first: \(s(-1) = 0\text{.}\) Then use the formula: \(r(0) = 0^2 - 3 = -3\text{.}\) So \(r(s(-1)) = -3\text{.}\)
    🔗
    🔗
    🔗

    (c)

    \(r(s(3))\)
    🔗
    Answer.
    Use the table first: \(s(3) = 2\text{.}\) Then use the formula: \(r(2) = 2^2 - 3 = 1\text{.}\) So \(r(s(3)) = 1\text{.}\)
    🔗
    🔗
    🔗

    (d)

    \(s(r(0))\)
    🔗
    Answer.
    Use the formula first: \(r(0) = -3\text{.}\) That makes the outer value \(s(-3)\text{,}\) but \(-3\) is not an input in the table. The value \(s(r(0))\) does not exist.
    🔗
    🔗
    🔗
    🔗

    5. Problem 5: Composition in Context.

    Let \(m = d(t)\) be the number of miles traveled \(t\) hours after starting a trip, and let \(k = c(m) = 1.61m\) be the function that converts \(m\) miles to \(k\) kilometers. Define a new function by \(f(t) = c(d(t))\text{.}\)
    🔗

    (a)

    What are the input and the output of \(f\text{?}\) Include units.
    🔗
    Answer.
    The input of \(f\) is the input of \(d\text{,}\) time in hours. The output of \(f\) is the output of \(c\text{,}\) distance in kilometers.
    🔗
    🔗
    🔗

    (b)

    Write a full sentence explaining what \(f(t)\) represents.
    🔗
    Answer.
    The value \(f(t)\) is the number of kilometers traveled \(t\) hours after the trip started. The function \(d\) turns the time into miles, and then \(c\) turns those miles into kilometers.
    🔗
    🔗
    🔗

    (c)

    Suppose the car travels at a steady speed, so that \(d(t) = 60t\text{.}\) Find and simplify a formula for \(f(t)\text{.}\) Then find \(f(2)\) and explain what it means.
    🔗
    Answer.
    Substitute \(60t\) for the input of \(c\text{.}\)
    \begin{align*} f(t) \amp= c(60t) = 1.61(60t) = 96.6t\\ f(2) \amp= 96.6(2) = 193.2 \end{align*}
    🔗
    Two hours after the trip started, the car had traveled \(193.2\) kilometers.
    🔗
    🔗
    🔗

    (d)

    Explain why \(d(c(m))\) does not make sense in this situation.
    🔗
    Answer.
    The output of \(c\) is a distance in kilometers, but the input of \(d\) must be a time in hours. The output of the inside function does not match the kind of input the outside function expects, so the composition has no meaning here.
