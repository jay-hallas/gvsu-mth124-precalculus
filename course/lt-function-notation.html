    Worksheet Learning Target: Function Notation
    

    Objectives

    • I can use function notation, find and simplify the output of a function given an input, and find an input that produces a given output; I can do this for functions given by a formula, a table, and a graph.
      🔗
    🔗

    1. Problem 1: A Function Given by a Formula.

    Let \(\displaystyle g(x) = \frac{24}{3x+2}\text{.}\)
    🔗

    (a)

    Find \(g(2)\text{.}\)
    🔗
    Answer.
    \(\displaystyle g(2) = \frac{24}{3(2)+2} = \frac{24}{8} = 3\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find \(g(-1)\text{.}\) Show each step of your simplification.
    🔗
    Answer.
    \(\displaystyle g(-1) = \frac{24}{3(-1)+2} = \frac{24}{-3+2} = \frac{24}{-1} = -24\text{.}\)
    🔗
    The negative input has to be wrapped in parentheses before multiplying, and the denominator has to be finished off before dividing.
    🔗
    🔗
    🔗

    (c)

    Find the input \(x\) that produces an output of \(4\text{.}\)
    🔗
    Answer.
    We are solving \(\displaystyle \frac{24}{3x+2} = 4\text{.}\) Multiplying both sides by \(3x+2\) gives \(24 = 4(3x+2)\text{,}\) so \(24 = 12x+8\) and \(16 = 12x\text{.}\)
    🔗
    The input is \(\displaystyle x = \frac{4}{3}\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Is there an input value that this function cannot accept? If so, state it and explain what goes wrong there.
    🔗
    Answer.
    The input \(\displaystyle x = -\frac{2}{3}\) has to be excluded. It makes the denominator \(3x+2\) equal to zero, and division by zero is undefined.
    🔗
    🔗
    🔗
    🔗

    2. Problem 2: A Function Given by a Table.

    The function \(h\) is defined by the table below.
    🔗
    \(x\) \(-3\) \(-1\) \(0\) \(2\) \(5\) \(8\)
    \(h(x)\) \(12\) \(5\) \(-4\) \(5\) \(0\) \(12\)

    (a)

    Find \(h(0)\) and \(h(5)\text{.}\)
    🔗
    Answer.
    \(h(0) = -4\) and \(h(5) = 0\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find all inputs \(x\) for which \(h(x) = 12\text{.}\)
    🔗
    Answer.
    \(x = -3\) and \(x = 8\text{.}\) Two different inputs are allowed to share an output, so both count.
    🔗
    🔗
    🔗

    (c)

    Find all inputs \(x\) for which \(h(x) = 0\text{.}\) Then explain how this question is different from finding \(h(0)\text{.}\)
    🔗
    Answer.
    \(x = 5\text{.}\)
    🔗
    To find \(h(0)\text{,}\) you start in the input row at \(0\) and read the output underneath it. To solve \(h(x) = 0\text{,}\) you start in the output row at \(0\) and read back every input above it.
    🔗
    The two questions move through the table in opposite directions, and they happen to have different answers here.
    🔗
    🔗
    🔗

    (d)

    A different rule is recorded in the table below. Can this rule be a function? Why or why not?
    🔗
    \(x\) \(1\) \(4\) \(6\) \(4\)
    \(y\) \(9\) \(2\) \(9\) \(-7\)
    Answer.
    No. The input \(4\) is assigned two different outputs, \(2\) and \(-7\text{,}\) and a function has to assign exactly one output to each input.
    🔗
    The repeated output \(9\) is not a problem. Nothing in the definition says two inputs cannot share an output.
    🔗
    🔗
    🔗
    🔗

    3. Problem 3: A Function Given by a Graph.

    The function \(f\) is defined by the graph below.
    🔗
    
    The graph consists of three connected line segments drawn on a coordinate grid. The first segment falls from the point negative four, two to the point negative two, negative two. The second segment rises from negative two, negative two to the point two, two. The third segment falls from two, two to the point four, zero. The graph crosses the horizontal axis at negative three, at the origin, and at four.
    🔗

    (a)

    Find \(f(1)\) and \(f(-2)\text{.}\)
    🔗
    Answer.
    \(f(1) = 1\) and \(f(-2) = -2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find all inputs \(x\) for which \(f(x) = 0\text{.}\)
    🔗
    Answer.
    \(x = -3\text{,}\) \(x = 0\text{,}\) and \(x = 4\text{.}\) These are the three places where the graph meets the horizontal axis.
    🔗
    🔗
    🔗

    (c)

    Find all inputs \(x\) for which \(f(x) = 2\text{.}\)
    🔗
    Answer.
    \(x = -4\) and \(x = 2\text{.}\) One is the left endpoint of the graph and the other is the peak in the middle.
    🔗
    🔗
    🔗

    (d)

    Sketch a graph that is not a function, assuming the horizontal axis holds inputs and the vertical axis holds outputs. Mark one input on your sketch that shows why it fails.
    🔗
    Answer.
    Any graph where some vertical line hits the curve more than once will work.
    🔗
    A circle centered at the origin is one example. The input \(x = 0\) is paired with two outputs, one at the top of the circle and one at the bottom, so the rule does not assign exactly one output to that input.
    🔗
    🔗
    🔗
    🔗

    4. Problem 4: Function Notation in Context.

    A driver leaves Grand Rapids for a trip downstate. The distance still remaining in the trip, \(D\text{,}\) measured in miles, is a function of the time \(t\text{,}\) measured in hours since the driver left. Write \(D = f(t)\text{.}\)
    🔗

    (a)

    Identify the input and output variables, and state the units of each.
    🔗
    Answer.
    The input is the time since the driver left, measured in hours. The output is the distance remaining, measured in miles.
    🔗
    🔗
    🔗

    (b)

    Explain in writing what \(f(3) = 145\) means in this situation.
    🔗
    Answer.
    Three hours after the driver left, there are still 145 miles left in the trip.
    🔗
    A complete interpretation names the input value, the output value, and the units on each, without using the letters \(f\) or \(t\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Explain what the equation \(f(t) = 0\) is asking, and describe what a solution to it would tell you about the trip. How is this different from the previous question?
    🔗
    Answer.
    It asks for the time at which the distance remaining is zero miles, so a solution is the number of hours the whole trip took.
    🔗
    In the previous question the input was handed to us and we reported the output. Here the output is handed to us and we solve backwards for the input.
    🔗
    🔗
    🔗

    (d)

    Suppose you divide the change in \(D\) by the change in \(t\) over the first three hours. What units does that value carry, and what does it tell you about the drive?
    🔗
    Answer.
    The units are miles per hour. It is the average rate at which the distance remaining is changing, which is the driver’s average speed over those three hours.
    🔗
    The value comes out negative, since the distance remaining is going down as time goes up.
    🔗
    🔗
    🔗
    🔗

    5. Problem 5: Inputs That Are Not Numbers.

    Let \(f(x) = x^2 - 3x\text{.}\)
    🔗

    (a)

    Find \(f(-2)\text{.}\)
    🔗
    Answer.
    \(f(-2) = (-2)^2 - 3(-2) = 4 + 6 = 10\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find \(f(x+2)\) and simplify completely. Substitute the entire expression \(x+2\) everywhere an \(x\) appears.
    🔗
    Answer.
    \(f(x+2) = (x+2)^2 - 3(x+2) = x^2 + 4x + 4 - 3x - 6 = x^2 + x - 2\text{.}\)
    🔗
    The common error here is writing \(x^2 + 4\) for \((x+2)^2\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find \(f(x) + f(2)\) and simplify. Compare your result to the previous answer and explain what the comparison shows about function notation.
    🔗
    Answer.
    Since \(f(2) = 4 - 6 = -2\text{,}\) we get \(f(x) + f(2) = x^2 - 3x - 2\text{.}\)
    🔗
    This is not the same as \(f(x+2) = x^2 + x - 2\text{.}\) The notation \(f(x+2)\) means the function is applied to the single input \(x+2\text{;}\) it does not mean the output at \(x\) and the output at \(2\) get added together.
    🔗
    Function notation does not distribute across a sum.
    🔗
    🔗
    🔗
