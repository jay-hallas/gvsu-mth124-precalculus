    Worksheet Learning Target: Function Notation
    

    Objectives

    • I can use function notation, find and simplify the output of a function given an input, and find an input that produces a given output; I can do this for functions given by a formula, a table, and a graph.
      🔗
    🔗

    1. A Function Given by a Formula.

    Suppose \(\displaystyle g(x) = \frac{30}{4x+2}\text{.}\)
    🔗

    (a)

    Determine \(g(1)\text{.}\)
    🔗
    Answer.
    Replacing \(x\) with \(1\) gives \(\displaystyle g(1) = \frac{30}{4(1)+2} = \frac{30}{6} = 5\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine \(g(-2)\text{.}\) Show each step of the simplification.
    🔗
    Answer.
    Wrap the negative input in parentheses:
    🔗
    \(\displaystyle g(-2) = \frac{30}{4(-2)+2} = \frac{30}{-8+2} = \frac{30}{-6} = -5\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find the input \(x\) that produces an output of \(3\text{.}\) That is, solve \(g(x) = 3\text{.}\)
    🔗
    Answer.
    Set the formula equal to \(3\) and clear the denominator:
    🔗
    \(\displaystyle \frac{30}{4x+2} = 3\text{,}\) so \(30 = 3(4x+2)\text{,}\) so \(30 = 12x + 6\text{,}\) so \(24 = 12x\) and \(x = 2\text{.}\)
    🔗
    Check: \(\displaystyle g(2) = \frac{30}{10} = 3\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Is there any input value that is not allowed for \(g\text{?}\) If so, give it and explain what goes wrong.
    🔗
    Answer.
    The denominator is zero when \(4x + 2 = 0\text{,}\) that is, when \(x = -\frac{1}{2}\text{.}\) Division by zero is undefined, so \(-\frac{1}{2}\) is not an allowed input. Every other real number is fine.
    🔗
    🔗
    🔗
    🔗

    2. Evaluating and Solving Backwards.

    Let \(h(t) = 2t^2 + t - 6\text{.}\)
    🔗

    (a)

    Determine \(h(0)\text{.}\)
    🔗
    Answer.
    \(h(0) = 2(0)^2 + 0 - 6 = -6\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine \(h(-3)\text{.}\)
    🔗
    Answer.
    \(h(-3) = 2(-3)^2 + (-3) - 6 = 2(9) - 3 - 6 = 18 - 9 = 9\text{.}\)
    🔗
    Squaring happens before multiplying by \(2\text{,}\) so the first term is \(18\) and not \(-18\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find all inputs \(t\) for which \(h(t) = 0\text{.}\)
    🔗
    Answer.
    Solve \(2t^2 + t - 6 = 0\text{.}\) Factoring gives \((2t - 3)(t + 2) = 0\text{,}\) so \(t = \frac{3}{2}\) or \(t = -2\text{.}\)
    🔗
    Two different inputs share the output \(0\text{.}\) That is allowed for a function; what is not allowed is one input having two outputs.
    🔗
    🔗
    🔗

    (d)

    Now let \(q(x) = x^2 + 2x\text{.}\) Determine \(q(x-1)\) and simplify completely. Substitute the entire expression \(x-1\) everywhere you see an \(x\text{.}\)
    🔗
    Answer.
    \(q(x-1) = (x-1)^2 + 2(x-1) = x^2 - 2x + 1 + 2x - 2 = x^2 - 1\text{.}\)
    🔗
    A common error is writing \(x^2 + 1\) for \((x-1)^2\text{.}\) Expand the square fully before combining terms.
    🔗
    🔗
    🔗
    🔗

    3. A Function Given by a Table.

    The function \(p(x)\) is defined by the table below.
    🔗

    (a)

    Determine \(p(0)\text{.}\)
    🔗
    \(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\) \(3\)
    \(p(x)\) \(8\) \(3\) \(-4\) \(3\) \(12\) \(-4\)
    Answer.
    Find \(0\) in the input row and read down: \(p(0) = -4\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find all inputs \(x\) for which \(p(x) = 3\text{.}\)
    🔗
    Answer.
    The output \(3\) appears twice, above the inputs \(-1\) and \(1\text{.}\) So \(x = -1\) and \(x = 1\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find all inputs \(x\) for which \(p(x) = 0\text{.}\) Explain why this is a different question from part (a).
    🔗
    Answer.
    The output row never shows \(0\text{,}\) so the table gives no input with \(p(x) = 0\text{.}\)
    🔗
    In part (a) the input was handed to us and we read the output. Here the output is handed to us and we work backwards through the table looking for every matching input. The notation \(p(0)\) puts \(0\) in the input slot; the equation \(p(x) = 0\) puts \(0\) in the output slot.
    🔗
    🔗
    🔗

    (d)

    Consider the rule defined by this second table. Can this rule be a function? Why or why not?
    🔗
    \(x\) \(-1\) \(0\) \(3\) \(3\)
    \(y\) \(4\) \(10\) \(22\) \(9\)
    Answer.
    No. The input \(3\) is assigned two different outputs, \(22\) and \(9\text{.}\) A function must send each input to exactly one output, so this rule cannot be a function.
    🔗
    🔗
    🔗
    🔗

    4. A Function Given by a Graph.

    The function \(f(x)\) is defined by the graph below. Read your values directly from the grid.
    🔗
    
    A graph on a coordinate grid with x from negative 5 to 4 and y from negative 3 to 5. The graph is made of three connected straight segments. The first rises from the point (negative 5, 1) to the point (negative 2, 4). The second falls from (negative 2, 4) through (0, 0) to the point (1, negative 2). The third rises from (1, negative 2) through (3, 0) to the point (4, 1). The graph has endpoints at (negative 5, 1) and (4, 1).
    🔗

    (a)

    Determine \(f(-1)\text{.}\)
    🔗
    Answer.
    At \(x = -1\) the graph is on the falling middle segment, at the point \((-1, 2)\text{.}\) So \(f(-1) = 2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Determine \(f(2)\text{.}\)
    🔗
    Answer.
    At \(x = 2\) the graph is on the rising right segment, at the point \((2, -1)\text{.}\) So \(f(2) = -1\text{.}\)
    🔗
    🔗
    🔗

    (c)

    Find all inputs \(x\) for which \(f(x) = 0\text{.}\)
    🔗
    Answer.
    The graph touches the \(x\)-axis at \((0,0)\) and at \((3,0)\text{,}\) so \(f(x) = 0\) when \(x = 0\) and when \(x = 3\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Find all inputs \(x\) for which \(f(x) = 2\text{.}\)
    🔗
    Answer.
    Reading across at a height of \(2\text{,}\) the graph passes through \((-4, 2)\) on the first segment and \((-1, 2)\) on the second. The third segment never reaches a height of \(2\) before the graph ends at \((4,1)\text{.}\) So \(x = -4\) and \(x = -1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    5. Function Notation in Context.

    A candle is lit and burns down steadily. Let \(H(t)\) be the height of the candle in centimeters, \(t\) hours after it was lit.
    🔗

    (a)

    Explain in writing what \(H(3) = 11\) means in this situation. Use a full sentence with units and avoid the letters \(H\) and \(t\text{.}\)
    🔗
    Answer.
    Three hours after the candle was lit, it is \(11\) centimeters tall.
    🔗
    🔗
    🔗

    (b)

    Explain what the equation \(H(t) = 5\) is asking, and describe what a solution to it would tell you about the candle. How is this different from the statement in part (a)?
    🔗
    Answer.
    The equation asks for the time, or times, at which the candle is \(5\) centimeters tall. A solution is a number of hours since the candle was lit.
    🔗
    In part (a) the input was given and the output was reported. Here the output is given and we solve backwards for the input.
    🔗
    🔗
    🔗

    (c)

    Consider the rule that sends each song on an album to its length in seconds. Do you think this could be a function? Why or why not?
    🔗
    Answer.
    Yes. Each song has exactly one length, so every input is assigned exactly one output. Two different songs could easily have the same length, but that does not break the definition; sharing an output is allowed.
    🔗
    🔗
    🔗

    (d)

    Sketch a graph that is not a function, assuming the horizontal axis represents input values and the vertical axis represents output values. Explain how you know your graph fails to be a function.
    🔗
    Answer.
    Answers will vary. Any graph with two or more points stacked directly above one another works. A circle centered at the origin, a sideways parabola such as \(x = y^2\text{,}\) or a vertical line all qualify.
    🔗
    The reason in every case is the same: there is at least one input value with more than one output. A vertical line drawn at that input crosses the graph more than once.
    🔗
    🔗
    🔗
