    Worksheet Learning Target 1: Function Notation and Functions
    

    Objectives

    • I can use function notation, find and simplify the output of a function given an input, and find an input that produces a given output; I can do this for functions given by a formula, a table, and a graph.
      🔗
    🔗

    1. Evaluating Functions Given by Formulas.

    (a)

    Suppose \(g(x) = \frac{20}{2x+1}\text{.}\) What is \(g(2)\text{?}\)
    🔗
    Answer.
    Substitute \(2\) for \(x\text{:}\)
    🔗
    \(g(2) = \frac{20}{2(2)+1} = \frac{20}{5} = 4\text{.}\)
    🔗
    Therefore, \(g(2) = 4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    2. Evaluate and Simplify.

    (a)

    Suppose \(f(x) = \frac{x^2 - 9}{x-3}\text{.}\) Find and simplify \(f(5)\text{.}\)
    🔗
    Answer.
    Substitute \(5\) for \(x\text{:}\)
    🔗
    \(f(5) = \frac{5^2 - 9}{5-3} = \frac{25-9}{2} = \frac{16}{2} = 8\text{.}\)
    🔗
    Therefore, \(f(5) = 8\text{.}\)
    🔗
    🔗
    🔗
    🔗

    3. Finding Input Given Output.

    (a)

    Suppose \(h(x) = 4x - 7\text{.}\) Find the input \(x\) for which \(h(x) = 13\text{.}\)
    🔗
    Answer.
    We want the output to be \(13\text{,}\) so solve \(4x - 7 = 13\text{.}\)
    🔗
    Add \(7\) to both sides: \(4x = 20\text{.}\)
    🔗
    Divide by \(4\text{:}\) \(x = 5\text{.}\)
    🔗
    Therefore, the input that produces an output of \(13\) is \(5\text{.}\)
    🔗
    🔗
    🔗
    🔗

    4. Finding Multiple Inputs.

    (a)

    Suppose \(p(x) = (x+1)^2\text{.}\) Find all inputs that produce an output of \(9\text{.}\)
    🔗
    Answer.
    We want \(p(x) = 9\text{,}\) so solve \((x+1)^2 = 9\text{.}\)
    🔗
    Taking the square root gives \(x+1 = 3\) or \(x+1 = -3\text{.}\)
    🔗
    Therefore, \(x = 2\) or \(x = -4\text{.}\)
    🔗
    Both inputs produce an output of \(9\text{.}\) Thus the inputs are \(2\) and \(-4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    5. Identifying Functions from Tables.

    (a)

    Consider the rule defined by the table below.
    🔗
    \(x\) \(0\) \(1\) \(2\) \(2\)
    \(y\) \(0\) \(70\) \(105\) \(170\)
    Can this rule be a function? Explain why or why not.
    🔗
    Answer.
    No. This rule cannot be a function because the input \(x = 2\) is paired with two different outputs, \(105\) and \(170\text{.}\)
    🔗
    A function must assign exactly one output to each input.
    🔗
    🔗
    🔗
    🔗

    6. Real-World Functions.

    (a)

    Consider a rule that sends a paper book to the number of pages in it. Do you think this could be a function? Explain why or why not.
    🔗
    Answer.
    Yes. This could be a function because each particular physical paper book has exactly one number of pages.
    🔗
    Two different books may have the same number of pages, and that does not prevent the rule from being a function. What matters is that one input does not produce two different outputs.
    🔗
    🔗
    🔗
    🔗

    7. Interpreting Function Notation.

    (a)

    Suppose water is being drained from a pool and \(V(t)\) is the volume of water, in cubic feet, \(t\) hours after we started draining the pool. Explain in writing what \(V(4) = 3000\) means.
    🔗
    Answer.
    The statement \(V(4) = 3000\) means that \(4\) hours after we started draining the pool, the volume of water in the pool is \(3000\) cubic feet.
    🔗
    🔗
    🔗
    🔗

    8. Evaluating Functions from Tables.

    (a)

    The table gives values for a function \(f\text{.}\)
    🔗
    \(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
    \(f(x)\) \(5\) \(2\) \(1\) \(2\) \(5\)
    Answer each of the following questions.
    🔗
    1. Find \(f(-1)\text{.}\)
      🔗
    2. Find \(f(2)\text{.}\)
      🔗
    3. Find all inputs that produce an output of \(5\text{.}\)
      🔗
    Answer.
    Reading the output corresponding to each input from the table gives \(f(-1) = 2\) and \(f(2) = 5\text{.}\)
    🔗
    An output of \(5\) occurs when \(x = -2\) and when \(x = 2\text{.}\) Therefore, the inputs that produce an output of \(5\) are \(-2\) and \(2\text{.}\)
    🔗
    🔗
    🔗
    🔗

    9. Evaluating Functions from Graphs.

    (a)

    The graph below represents a function \(f\text{.}\)
    🔗
    
    A coordinate graph with horizontal axis labeled \(x\) and vertical axis labeled \(f(x)\text{.}\) Connected line segments form a V-shaped graph through the points (-4,4), (0,0), and (4,4).
    🔗
    Use the graph to answer each question.
    🔗
    1. Find \(f(-2)\text{.}\)
      🔗
    2. Find \(f(0)\text{.}\)
      🔗
    3. Find \(f(2)\text{.}\)
      🔗
    4. Find all inputs that produce an output of \(4\text{.}\)
      🔗
    Answer.
    Reading the corresponding output values from the graph gives \(f(-2) = 2\text{,}\) \(f(0) = 0\text{,}\) and \(f(2) = 2\text{.}\)
    🔗
    The graph has an output of \(4\) when \(x = -4\) and when \(x = 4\text{.}\) Therefore, the inputs producing an output of \(4\) are \(-4\) and \(4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    10. Recognizing Functions from Graphs.

    (a)

    Give an example of a graph that is not a function if the horizontal axis represents input values and the vertical axis represents output values. Explain how you know the graph is not a function.
    🔗
    Hint: Think about whether one input value could have more than one output.
    🔗
    Answer.
    One example is a circle. A vertical line through the center of the circle intersects the graph at two points, which means that the same input value would have two different outputs. Therefore, the graph does not represent a function.
    🔗
    
    A coordinate graph containing a circle centered at the origin. A vertical line through the center intersects the circle at two points, demonstrating that the graph does not represent a function.
